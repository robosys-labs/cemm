# CEMM foundation architecture

## Executable owners

```text
Text/Evidence
  -> ORIENT: one immutable, revision-pinned ProposalContext
  -> PROPOSE: typed bounded candidate programs (reference deterministic)
  -> VERIFY: exact coverage, graph, scope and canonical expression identity
  -> EVALUATE: typed query/admission/intent based only on VerifiedMeaning
  -> EFFECT: exclusive idempotent mutation/adapter gateway
  -> REALIZE: currently a lossless structured ResponseMeaning protocol only
```

The current R3 predecessor deliberately marks natural-language REALIZE as a
later-owner gap. The foundation's structured output codec carries the exact
verified response and its decision/effect/provenance without paraphrasing it.
That is not evidence of ordinary conversational language realization.

The knowledge substrate uses five persistent operators:
DESIGNATION, TYPE, RELATION, STATE, EVENT. Logical scope, attribution,
composition, variables, temporal context and epistemic placement are explicit
additional expression/interpretation structures, NOT a sixth persistent
fact operator.

## Safety invariants

1. Only one active cognition/effect owner.
2. A proposal program is never meaning or world truth.
3. Scoped statements (attribution, negation, time) never collapse to
   unqualified observations.
4. Unknown forms create typed unresolved evidence, never new atoms.
5. Read-only queries and simulations cannot create world facts.
6. Effect receipts are tied to verified meaning, authorization and revision.
7. No user-facing linguistic surface is accepted via keyword or template checks.
8. Every admitted semantic protocol surface is reversible to the original
   ResponseMeaning with its proof and exact effect receipt.

## Not yet proven

Novel-designation learning through a complete live conversation and restart;
general compositional sentence transfer; quantified query semantics; semantically
checked natural-language realization; model calibration and release neural
proposal; standalone authority-packaged distribution. These are blockers for
general cognitive release, not permission to revive historical pathways.
