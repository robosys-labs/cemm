# Archived CEMM Documents

Files below this directory are historical evidence only. They may explain why a prior implementation existed, but they are not implementation authority and must not be used to preserve obsolete behavior.

Active root contracts are listed in `AGENTS.md`.

## Archival rules

Archive a root document when:

- its phase plan has been executed or superseded;
- its issue list describes a retired runtime;
- its test expectations encode compatibility behavior;
- its status language conflicts with current evidence;
- keeping it active could cause a developer to implement two architectures.

Do not silently delete history. Move it here, add an archive banner, and record the successor document.
