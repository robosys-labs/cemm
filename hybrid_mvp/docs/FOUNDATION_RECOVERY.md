# Canonical foundation recovery — branch acceptance

This branch is a **semantic-protocol vertical slice**, not a claim that R5
natural-language generation or neural release activation is finished.

## Nonnegotiable ownership

1. Exactly one cognitive engine is used: `HybridRuntime`.
2. `FoundationRuntime` cannot ground, infer, mutate, authorize, or generate
   alternate meaning. It delegates to the existing runtime.
3. The sixth boundary is a **lossless typed semantic surface**, whose entire
   ResponseMeaning is round-tripped and revision/effect provenance checked.
4. It is **not** a natural-language realizer; no marker-based verifier,
   template-selector, or hashed-text bucket is allowed to be called equivalent.
5. Unknown input cannot become a guessed claim or successful answer.
6. External adapters are not installed for the reference foundation.
7. Historical R3/R4/R5 test inventory and replay ledger remain unchanged.
   Passing this vertical slice does not promote those phases.

## Required cutover follow-up

- Reconcile `NeuralSwitchProposer.propose(orientation)` against
  `ProposalOwner.propose(context)` **before** any neural model is admitted.
- Eliminate direct `ProposalResult(...)` construction and instantiate ranked
  candidates using exact ABI 2 factories.
- Implement independently checked natural-language graph equivalence and
  atomic response outcome delivery; replace the R5 gap only when admitted.
- Promote one canonical CycleResult and move the former `cycle.py` result
  into the historical/fixture layer after its consumers are migrated.
- Move root Stage 0–22 code and historical artifacts out of installable paths
  after isolated new-foundation test and clean-import gates pass.
- Build independent golden evidence scenarios with compositional/temporal/
  attribution/negation/learning/effect canaries before expanding authority.
- Retain evidence-bearing histories in Git without placing executable legacy
  modules or historical release files on the default import path.

Do not claim end-to-end **conversational** cognition until the text output is
semantically checked. The present runnable foundation proves end-to-end
**structured-semantic** output only.
