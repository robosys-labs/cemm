## Matched observed histories and target formation

For each of both NAND/NOR laws and all five seeds (7, 11, 23, 37, 53), deterministically choose the same six metadata-only TRAIN site triples used in v2. Each triple uses different entities, lineages and all three surface orders. For each triple enumerate `old,regional,sentinel,reading` in `{0,1}^4` (96 prefixes per law/seed). For **both** latent reversal possibilities, generate:

1. **PRE:** remove the later probe receipt entirely; the two opposite latent target outcomes have exactly identical public records, scope, selected action and candidate forecasts. Feed each observed selected-action payoff to a *proper* log-likelihood loss. Audit confidence before seeing either payoff.
2. **POST:** add one verified, physically discriminating later probe to that same history; score the selected action payoff for the local meaning and audit whether the recovered decision is confidently correct.
3. **RETAIN:** after POST, score selected-action payoffs for sibling region, outside/root and independent sentinel. Verify no loss of earlier knowledge.

All future payoffs are generated by selecting one fixed physical action from the native TRAIN site for both twins. Training receives only the attributed history, scope, selected action's conditional forecasts and **the actual observed payoff**. Reversal, interpretation labels, true scopes and future payoffs are evaluator/generator-only; never model input. Audit payload may inspect those truths *after* predictions. Candidate forecasts and the nested scope hierarchy are supplied biases, not learned meanings. These cases reuse previously exposed TRAIN physical structure, so the study is diagnostic, not a new blind test.

Prespecified per-condition counts: **192 PRE + 192 POST + 576 RETAIN = 960 observations**, each containing a selected-payoff and 2D candidate probabilities. Count counterfactual twins as dependent pairs, not independent environments.
